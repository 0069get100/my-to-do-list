# Little Day · 我的小日常

浅色马卡龙风格的个人待办网页，支持手机和桌面屏幕，无需账户或后端数据库。

## 运行

需要 Node.js 20 或更高版本。

```sh
npm ci
npm start
```

在浏览器打开 `http://localhost:3000`。可通过 `PORT=8080 npm start` 修改端口；`npm run dev` 同样启动开发服务。前端为原生 HTML、CSS 和 JavaScript，无需构建，修改后刷新即可。

## 功能

- 添加任务，选择高 / 普通 / 低优先级和可选截止日期。
- 勾选完成或恢复待完成，删除任务。
- 查看所有任务、今天的任务、已完成任务，并按完成状态筛选。
- 按添加时间、优先级或截止日期排序，无日期任务在日期排序中靠后。
- 全部任务完成进度条，以及今天任务总数、已完成数、待完成数。
- 本地自动保存，刷新后恢复；存储受限时显示提示。

“今天的任务”指截止日期为本地今天的任务；无日期任务只进入全部任务。逾期未完成任务有标记。任务数据保存在当前浏览器的 localStorage，不跨设备同步，清除站点数据会删除任务。

## 测试

```sh
npm test
```

测试使用 Node.js 测试运行器和 jsdom，覆盖添加、完成、恢复、删除、本地记录恢复、今日统计、进度、筛选、排序、输入安全及存储失败。生产运行不依赖第三方包。
